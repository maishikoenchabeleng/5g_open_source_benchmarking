# Open5GS Configuration Files

Config files for the Open5GS core network used in this project.

| File | Purpose |
|------|---------|
| `amf.yaml` | AMF configuration (PLMN, NGAP, TAC) |
| `smf.yaml` | SMF configuration (session management) |
| `upf.yaml` | UPF configuration (user plane, GTP-U) |

For what was changed and why, see [docs/Implementation.md](../../docs/Implementation.md).
