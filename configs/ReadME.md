# Configuration Files

This folder contains the open-source configuration files that were **modified** for this project. Unmodified default files are not committed, only files that were edited to configure the testbed are tracked added here.

| Folder | Component | Purpose |
|--------|-----------|---------|
| `open5gs/` | Open5GS core network | Modified configs for Open5GS |
| `free5gc/` | Free5GC core network | Modified configs for Free5GC |
| `oai-ran/` | OpenAirInterface RAN | Modified configs for OAI gNB |
| `srsran/` | srsRAN (OCUDU) | Modified configs for srsRAN gNB |
| `ueransim/` | UERANSIM UE simulator | Modified configs for UERANSIM |


For what each config file does and why, see [docs/Implementation.md](../docs/Implementation.md).
