# Configuration Files

This folder contains the open-source code with the configuration files that were used and adapted to match the components of this project.

| Folder | Component |
|--------|-----------|
| `open5gs/` | Open5GS core network |
| `free5gc/` | Free5GC core network |
| `oai-ran/` | OpenAirInterface RAN | 
| `srsran/` | srsRAN (OCUDU) | 
| `ueransim/` | UERANSIM UE simulator | 

For what each config file does and why, see [docs/Implementation.md](../docs/Implementation.md).
