## Free5GC Configuration Files

Configuration files for Free5GC core network used in this project are:

| File | Purpose |
|------|---------|
| `amf.yaml` | AMF configuration (PLMN, NGAP, TAC) |
| `smf.yaml` | SMF configuration (session management) |
| `upf.yaml` | UPF configuration (user plane, GTP-U) |

For a detailed explanation on what was changed and why, see  [docs/Implementation.md](../../docs/Implementation.md).
