## Script Automation


This folder contains the scripts that were used to run and tests the different network combinations. Only four scripts were used to run these networks. Their descriptions can be found below:



| Script | Description |
|--------|-----------| 
| `5g_benchmark` | Runs the monolithic networks with **simulated UE** including UERANSIM simulations | 
| `5g_split_sim` | Runs the split architectures networks with **simulated UE** | 
| `5g_mono_hardware` | Runs the monolithic networks with **hardware UE** | 
| `5g_split_hardware` |Runs the split architecture networks with **simulated UE** |
