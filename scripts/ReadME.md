## Scripts


This folder contains the scripts that were used for running and testing the 5G testbed. Only four scripts were used to run these networks and are organized by deployment architecture and mode. Their descriptions can be found below:



| Script | Description |
|--------|-----------| 
| `5g_benchmark` | Runs the monolithic networks with **simulated UE** including UERANSIM simulations (no USRP hardware) | 
| `5g_split_sim` | Runs the split architectures networks with **simulated UE** | 
| `5g_mono_hardware` | Runs the monolithic networks with **real USRP hardware + real UE** | 
| `5g_split_hardware` |Runs the split 2 (CU/DU) architecture network with **real USRP hardware + real UE** |
